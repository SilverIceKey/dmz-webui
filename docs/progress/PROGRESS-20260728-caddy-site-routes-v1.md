# Caddy 域名与路径路由进度

## 当前状态

- 状态：代码与本地自动验证完成，等待目标服务器部署联调。
- 当前结论：SSL 代理页面已增加按域名和路径管理的反向代理、静态文件路由。
- 二级域名启用 SSL 时生成 Caddy Automatic HTTPS 站点，由 Caddy 自动签发
  和续签证书。

## 最近关键结论

- 路由配置保存在 `/etc/dmz-webui/site_routes.json`。
- 静态文件使用 `/var/lib/dmz-webui/caddy-static/<规则 ID>/` 专属目录，
  不接受任意系统绝对路径；删除路由保留文件。
- 主域名路由与既有 `/admin`、`/assets`、根跳转合并生成；子域名按 hostname
  生成独立站点。
- Headscale 等根路径代理支持真实客户端 IP 请求头；非根路径可配置是否去掉
  路径前缀。
- 二级域名 HTTPS 仅允许标准 443 模式；关闭 SSL 时生成显式 HTTP 站点。
- 部署、更新和运行时 API 统一调用 Python Caddyfile 生成入口，不再由 shell
  模板覆盖动态端口代理或站点路由。
- 后端 48 项测试通过；前端生产构建通过。
